At the core of our architecture is the compact set of learnable query tokens , where each token is tasked with discovering and representing a specific region of the 3D scene. These tokens serve as abstraction units that learn to aggregate relevant information from the extracted multi-view features to form coherent 3D Gaussians. Unlike per-pixel Gaussian estimation methods that rigidly map each pixel to Gaussians, our query tokens can flexibly attend to any region across all input views, learning to allocate representational capacity where it is most needed. This combined representation is processed through transformer layers with full self-attention, enabling bidirectional information flow. Through these attention layers, each query token learns to: (1) aggregate relevant visual information from specific regions across all input views, (2) exchange information with other query tokens to avoid redundancy and ensure comprehensive coverage, and (3) progressively refine its understanding of which 3D region it should represent. After the transformer blocks, we extract the refined query tokens and decode each token into a single Gaussian , estimating Gaussian attributes through lightweight MLP heads. Unlike previous methods that learn scene decompositions from ground-truth labels , adopting 3D Gaussians as our representation enables our framework to be learned solely through the objective of novel view synthesis. Previous methods for lifting 2D features to 3D face two fundamental challenges: (1) Correspondence identification: for each 2D patch whose features need to be lifted, they must identify which 3D Gaussians contribute to rendering that pixel location, often requiring computationally expensive backward mapping operations . (2) Multi-view inconsistency: since image encoders extract features independently for each view, patches corresponding to the same 3D region can produce different feature representations across views, requiring additional aggregation schemes . Surprisingly, we find that the learned self-attention patterns of can be used to sidestep both challenges elegantly. For the correspondence identification, each learnable token shows high attention weights to the regions in each image where the 3D Gaussians are projected, removing the need for expensive backward mapping.
