高效架构

高效的架构设计是增强视频生成的最直接、最有效的方法，从短片到具有长时空背景的持久、高保真世界模型。

4.1 Hierarchical & VAE Designs

基于视频的高效世界建模的通用框架涉及将高维时空信号分解为从粗到细的层次结构或紧凑的潜在空间。

4.1.1 Hierarchical and Pyramidal Generation

这种方法是一个多阶段的细化过程，其中基本模块建立了通用世界模型，然后是用于细节增强的专用模块。

4.1.2 Efficient VAE and Latent Compression

REGEN 通过放宽从精确再现到合理重建的解码标准，进一步扩展了这一点。

4.2 Long Context & Memory Mechanisms

基于视频的世界建模依赖于长期保持一致性。常见的方法是通过外部或隐式记忆来增强生成主干，作为模拟世界的持久存储。

4.2.1 Visual Memory

视觉记忆保留原始或半压缩的关键帧作为锚定生成的不同参考点。

4.2.2 Spatial Memory

EvoWorld 使用球形 3D 内存维护不断发展的全景世界，而 VMem 则为相机姿势查询构建面元索引的全局地图。

4.3 Efficient Attention

充分的注意力占据了视频生成中主要的端到端运行时间。为了处理高分辨率或长视野世界模拟的二次复杂性，高效的架构通过稀疏注意力、窗口注意力或线性注意力来近似完全注意力。

4.3.1 Sparse Attention

为了解决被忽视的查询端冗余问题，BSA 和 Astraea 提出了一种机制，可以选择性地与键值对一起或代替键值对来修剪查询。

4.3.2 Windowed Attention

为了解决有限感受野引起的潜在质量下降问题，各种工作提出将局部窗口与全局上下文机制相结合。

4.4 Extrapolation and RoPE

真实的世界模型必须模拟其视野之外的未来，需要修改旋转位置嵌入 (RoPE) 以防止分布漂移。

4.4.1 Frequency-Based Extrapolation

RIFLEx 识别出高频分量导致时间重复，并提出频移以实现 3 长度外推。

4.4.2 Mitigating Attention Dispersion

UltraViCo 将“注意力分散”（即远距离标记稀释学习模式）视为质量衰减的根本原因，并引入恒定的衰减因子来抑制远距离分数。

高效推理

为了应对这些挑战，高效的推理策略侧重于分配计算负载、减少冗余计算和量化。

5.1 Parallelism

并行推理对于将视频生成扩展到高分辨率、长持续时间和实时推理至关重要。在实践中，现有系统主要通过序列级划分、管道式执行和混合并行框架来提高推理效率，从而使多GPU实时生成成为可能。

5.2 Caching

FasterCache 通过将动态特征重用与无分类器引导 (CFG) 感知缓存相结合，进一步提高了免训练加速。虽然 Table 重点关注通用视频生成模型的基于缓存的加速结果，但最近的工作也开始探索基于视频的世界模型的缓存机制。

5.3 Pruning

视频扩散模型中的修剪技术旨在通过消除令牌、通道或层级别的冗余信息来减少计算负担。为了解决视频数据的空间分辨率和时间深度带来的巨大计算开销，最近的方法利用了视频内容和扩散生成过程中的冗余。

5.3.1 Token-Level Reduction

为了明确保留信息区域，它利用无分类器指导（CFG）幅度作为无成本指标来构建重要令牌的动态池，并从该池中采样目标令牌。

5.3.2 Structural Pruning

对于静态架构修剪，MobileVD 引入了一种可学习的门控机制来修剪冗余时间块，同时引入通道漏斗策略以在推理过程中压缩层宽度。

5.4 Quantization

量化降低了权重和激活的精度，以加速推理并降低内存使用量，这对于部署大规模基于视频的世界模型至关重要。我们将最新进展分为以注意力为中心的优化、训练后量化、量化感知训练和动态调度策略。

5.4.1 Attention-Centric Quantization

注意力机制在视频生成模型的计算成本中占主导地位，推动了从 8 位精度到 4 位精度的快速演变。

5.4.2 Post-Training Quantization

由于激活中存在明显的异常值，量化 DiT 具有挑战性，需要强大的训练后量化 (PTQ) 技术。 ViDiT-Q 是该领域的代表性方法，它通过 s 解决视频模型中的振荡激活问题。

5.5 Discussion

高效的视频推理侧重于减少每步延迟并扩展到高保真、长视野生成。本节回顾的四个方向从互补的角度解决了这个问题。
