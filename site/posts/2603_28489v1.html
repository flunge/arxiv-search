Video：作为世界模型的生成模型高效范式、架构和 A

原文标题：Video Generation Models as World Models Efficient Paradigms, Architectures and A

一句话总结： 视频生成的快速演进使模型能模拟复杂物理动态和长时域因果关系，将其定位为潜在的世界仿真器。然而世界仿真的理论能力和时空建模的重计算成本之间仍存在关键差距。本文全面系统性地综述了将效率作为实用世界建模关键要求的视频生成框架和技术：提出三维度的新颖分类法——高效建模范式、高效训练策略和高效推理技术；分析了各类方法在效率与质量之间的权衡；识别了当前方法的关键瓶颈和有前景的未来方向。该综述为构建实用、高效的视频世界模型提供了系统的参考框架。

简单摘要

视频生成技术经历了从早期GAN和像素级自回归模型到高保真扩散方法,再到能够建模物理定律和长时因果关系的世界模拟器的变革性演进。视频生成与世界建模的对齐具备三大优势:从多样化视频数据中涌现物理理解;潜想象的计算成本远低于高分辨率像素渲染;统一架构可横跨多个领域。然而实现视频世界模型的能力需要克服严峻的硬件限制——视频数据的高维性和物理动力学的复杂性导致巨大的计算和内存开销。本文首次系统性梳理效率改进技术如何赋能视频世界模型的各个层面。

核心创新

1. 提出该领域首个系统性综述,专门聚焦效率改进技术与视频世界模型多个层面的交汇。

2. 建立三维分类体系:高效建模、高效架构和高效推理,覆盖从建模到部署的完整技术栈。

3. 跨越自回归和扩散两条核心技术路线进行对比分析,系统性讨论二者在长序列生成中各自面临的内存爆炸和迭代去噪延迟等瓶颈及相应解决方案。

4. 首次将效率优化的学术讨论与自动驾驶、具身AI、游戏交互仿真等实际应用场景中的部署需求连接起来。

高效建模

高效建模对于在实际延迟和内存限制下将视频生成从短片段扩展到长视野、高分辨率序列至关重要。本节回顾两个主要方向。(i) 扩散模型蒸馏，减少高保真生成所需的采样步骤数量，以及 (ii) 长视野交互式建模范式，包括自回归、混合 AR 扩散。

3.1 Diffusion Model Distillation for Efficient Sampling

虽然架构和系统优化减少了每个步骤的挂钟延迟，但补充方向是训练后加速，可直接减少去噪步骤的数量。在基于扩散的视频生成中，采样成本与步数成线性比例。

3.1.1 Step-Reduction Distillation

直接方法将一步教师采样器提炼为一步学生采样器 。

3.1.2 Consistency Distillation

TurboDiffusion 引入了一个统一的框架，将一致性模型与奖励引导蒸馏相结合，显着提高了一步输出的视觉质量。

3.2 Auto-Regressive and Hybrid Approaches

自回归和混合方法旨在克服传统视频扩散模型（主要是基于剪辑的生成器）的局限性。通过将自回归时间推出与高效视频合成相结合，这些方法朝着持久、交互式和长视野的世界建模方向发展。

3.2.1 Auto-Regressive Modeling

沿着类似的方向，iVideoGPT 将世界建模制定为对视觉观察、动作和奖励的统一序列的下一个标记预测。

3.2.2 Hybrid AR-Diffusion Modeling

混合 AR 扩散建模旨在将自回归生成的长期推出能力与扩散模型的高保真合成能力相结合。

高效架构

高效的架构设计是增强视频生成的最直接、最有效的方法，从短片到具有长时空背景的持久、高保真世界模型。(ii) 长上下文和记忆机制，为全上下文建模提供可扩展的替代方案，以实现长范围一致性。(iii) 高效注意力，直接修剪计算主干，以通过稀疏、窗口或线性机制实现快速推理。

4.1 Hierarchical & VAE Designs

基于视频的高效世界建模的通用框架涉及将高维时空信号分解为从粗到细的层次结构或紧凑的潜在空间。

4.1.1 Hierarchical and Pyramidal Generation

这种方法是一个多阶段的细化过程，其中基本模块建立了通用世界模型，然后是用于细节增强的专用模块。

4.1.2 Efficient VAE and Latent Compression

REGEN 通过放宽从精确再现到合理重建的解码标准，进一步扩展了这一点。

4.2 Long Context & Memory Mechanisms

基于视频的世界建模依赖于长期保持一致性。常见的方法是通过外部或隐式记忆来增强生成主干，作为模拟世界的持久存储。

4.2.1 Visual Memory

视觉记忆保留原始或半压缩的关键帧作为锚定生成的不同参考点。

4.2.2 Spatial Memory

EvoWorld 使用球形 3D 内存维护不断发展的全景世界，而 VMem 则为相机姿势查询构建面元索引的全局地图。

4.3 Efficient Attention

充分的注意力占据了视频生成中主要的端到端运行时间。为了处理高分辨率或长视野世界模拟的二次复杂性，高效的架构通过稀疏注意力、窗口注意力或线性注意力来近似完全注意力。

4.3.1 Sparse Attention

为了解决被忽视的查询端冗余问题，BSA 和 Astraea 提出了一种机制，可以选择性地与键值对一起或代替键值对来修剪查询。

4.3.2 Windowed Attention

为了解决有限感受野引起的潜在质量下降问题，各种工作提出将局部窗口与全局上下文机制相结合。

4.4 Extrapolation and RoPE

真实的世界模型必须模拟其视野之外的未来，需要修改旋转位置嵌入 (RoPE) 以防止分布漂移。

4.4.1 Frequency-Based Extrapolation

RIFLEx 识别出高频分量导致时间重复，并提出频移以实现 3 长度外推。

4.4.2 Mitigating Attention Dispersion

UltraViCo 将“注意力分散”（即远距离标记稀释学习模式）视为质量衰减的根本原因，并引入恒定的衰减因子来抑制远距离分数。

高效推理

为了应对这些挑战，高效的推理策略侧重于分配计算负载、减少冗余计算和量化。(i) 并行性，通过空间、序列和管道分区将推理分布到多个设备上。

5.1 Parallelism

并行推理对于将视频生成扩展到高分辨率、长持续时间和实时推理至关重要。在实践中，现有系统主要通过序列级划分、管道式执行和混合并行框架来提高推理效率，从而使多GPU实时生成成为可能。

5.2 Caching

FasterCache 通过将动态特征重用与无分类器指导 (CFG) 感知缓存相结合，进一步提高了免训练加速。虽然 Table 重点关注通用视频生成模型的基于缓存的加速结果，但最近的工作也开始探索基于视频的世界模型的缓存机制。

5.3 Pruning

视频扩散模型中的修剪技术旨在通过消除令牌、通道或层级别的冗余信息来减少计算负担。为了解决视频数据的空间分辨率和时间深度带来的巨大计算开销，最近的方法利用了视频内容和扩散生成过程中的冗余。

5.3.1 Token-Level Reduction

为了明确保留信息区域，它利用无分类器指导（CFG）幅度作为无成本指标来构建重要令牌的动态池，并从该池中采样目标令牌。

5.3.2 Structural Pruning

对于静态架构修剪，MobileVD 引入了一种可学习的门控机制来修剪冗余时间块，同时引入通道漏斗策略以在推理过程中压缩层宽度。

5.4 Quantization

量化降低了权重和激活的精度，以加速推理并降低内存使用量，这对于部署大规模基于视频的世界模型至关重要。我们将最新进展分为以注意力为中心的优化、训练后量化、量化感知训练和动态调度策略。

5.4.1 Attention-Centric Quantization

注意力机制在视频生成模型的计算成本中占主导地位，推动了从 8 位精度到 4 位精度的快速演变。

5.4.2 Post-Training Quantization

DVD-Quant 通过重建校准数据来处理时间依赖性，将量化扩展到无数据设置，而 LRQ-DiT 解决了长尾的双重挑战。

5.5 Discussion

高效的视频推理侧重于减少每步延迟并扩展到高保真、长视野生成。本节回顾的四个方向从互补的角度解决了这个问题。

应用场景

通过高效视频生成的世界建模已广泛应用于自动驾驶、嵌入式人工智能和交互式游戏模拟等领域，支持数据合成等任务。在此类应用中，在线生成通常用于促进强化学习，而离线数据更常用于监督训练。

6.1 Autonomous Driving

6.1.1 Data Synthesis

InfinityDrive 引入了时空联合建模模块和扩展时间训练策略，可生成高分辨率时空一致的视频。

6.1.2 Interactive Simulation

一些作品将基于视频的世界模型集成到闭环交互管道中，推出用于交互模拟和评估的动作条件生成。

6.2 Embodied AI

6.2.1 Data Synthesis

为了缩小模拟与真实的差距，GenMimic 首先将人体运动视频提升为 4D 重建，然后将提取的人体运动重新定位为人形实施例。

6.2.2 Interactive Simulation

作为交互式环境模拟器，基于视频的世界模型可以支持稳定的动作条件推出生成以进行强化学习，并促进生成轨迹的实时评估。

6.3 Game & Interactive World Simulation

GameFactory 独立于游戏类型对动作控制进行建模，以便为不同的开放世界场景生成动作条件的交互式视频。WorldPlay强调高分辨率实时生成和动作调节下的长期一致性。

6.4 Discussion

视频生成模型在强大的世界建模能力的支持下，可以根据动作或指令预测未来的观察结果。在自动驾驶和嵌入式人工智能领域，一个明显的趋势是数据生成和交互模拟的逐渐融合。
