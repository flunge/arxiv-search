Bridging：通过统一可视化使用世界模型进行场景生成和规划驾驶

原文标题：Bridging Scene Generation and Planning Driving with World Model via Unifying Vis

一句话总结： 端到端自动驾驶旨在从原始传感器输入生成安全可行的规划策略，构建有效的场景表示是关键挑战。驾驶世界模型通过预测驾驶场景未来演化来学习丰富表示展现了巨大潜力，但现有方法主要关注视觉场景表示，运动表示并非显式设计为规划器可共享和可继承的。本文提出WorldDrive，一种通过统一视觉和运动表示来耦合场景生成与实时规划的整体框架：引入轨迹感知的驾驶世界模型以轨迹词汇表为条件强制视觉动态与运动意图的一致性；将视觉和运动编码器迁移到下游多模态规划器；提出未来感知奖励模型从冻结世界模型中蒸馏未来潜在表示以实时评估和选择最优轨迹。在NAVSIM和nuScenes上取得了领先的规划性能。

简单摘要

端到端自动驾驶旨在从原始传感器数据直接学习到行动的映射，其核心在于有效的视觉表征学习。驾驶世界模型（DWM）通过显式建模未来场景演化为预测复杂驾驶环境提供了强大基础。当前将DWM集成到规划的方案主要遵循两种范式：利用高保真模型生成未来场景供下游规划器使用（计算开销极大），或完全在潜空间世界模型中运行（虽更高效却牺牲了可解释的场景仿真）。作者识别出一个普遍存在的系统性局限——表示不匹配与任务脱节——场景模拟器优化感知重建而规划器独立训练进行行动回归，缺乏统一共享的表征。为此本文提出WorldDrive，一个通过统一视觉与运动表征来协同端到端规划与场景生成的整体框架，其核心理念是能够生成未来的潜在特征应与用于决策未来的特征一致。

核心创新

1. 提出轨迹感知驾驶世界模型（TA-DWM），采用基于预定义轨迹锚点的多模态轨迹编码方案，在结构化潜空间中将视觉动态与运动意图内蕴耦合。

2. 设计表示继承机制：将TA-DWM学得的鲁棒视觉和运动编码器直接迁移初始化下游规划器。

3. 构建轻量级多模态规划器，利用查询中心交叉注意力高效融合历史视觉上下文与结构化运动先验。

4. 提出未来感知奖励器（FAR），通过面向规划的蒸馏机制直接从冻结世界模型蒸馏未来潜变量来评估候选轨迹，保持实时推理速度。

技术细节

WorldDrive将场景生成与轨迹规划统一在一个整体框架中，通过统一视觉与运动表示桥接两个任务。系统在两个不同但耦合的阶段运行：视觉仿真阶段和轨迹优化阶段。

阶段一：轨迹感知驾驶世界模型（TA-DWM, Trajectory-aware Driving World Model）

基于强大的视频扩散模型构建，引入轨迹词汇表作为运动先验。具体组件：

3D因果VAE编码器：对历史观测O_hist进行编码。预训练3D因果VAE压缩时空维度。为将通用特征对齐到驾驶域，引入轻量可训练视觉适配器：Z_hist = Adapter(VAE_enc(O_hist))，得到时空视觉潜在表示Z_hist ∈ R^{T×H×W×C}。

多模态轨迹编码器（Multi-modal Trajectory Encoder）：将复杂的驾驶行为分解为粗粒度意图和细粒度调整。首先通过对大规模驾驶日志聚类构建轨迹词汇表V = {v_1, ..., v_K}，每个基元作运动锚点。给定专家轨迹τ_expert，从词汇表中检索top-K个最近锚点{v_k}，计算残差r_k = τ_expert - v_k以捕获运动细节。最终运动嵌入通过融合锚点嵌入和残差嵌入得到：E_motion = E_anchor({v_k}) + E_offset({r_k})，作为扩散模型的条件输入。

轨迹感知扩散Transformer（TA-DiT）：生成以历史上下文和运动意图为条件的未来潜在表示。训练时，真值未来帧F_future经VAE编码为目标潜在X_0。采用标准前向扩散过程获得噪声状态X_t = √(ᾱ_t)X_0 + √(1-ᾱ_t)ε，ε~N(0,I)。TA-DiT ε_θ(X_t, t, Z_hist, E_motion)优化为预测添加的噪声，目标为L_diff = E_{t,ε} ||ε - ε_θ||²。历史潜在Z_hist和运动嵌入E_motion共同引导生成过程在视觉一致性和运动学合理性之间平衡。

阶段二：多模态轨迹规划器（Multi-modal Trajectory Planner）

利用阶段一获得的结构化潜在空间，继承冻结的视觉编码器和轨迹编码器初始化规划器。这种表示继承策略确保规划器在有效和物理一致的特征上操作。

自车状态编码：轻量MLP编码自车状态（速度、加速度、驾驶指令）为嵌入E_ego。

轨迹规划作为集合预测问题：将完整的预定义锚点嵌入A = {a_1, ..., a_M}作为查询。上下文键和值通过拼接冻结的视觉潜在Z_hist和自车嵌入E_ego构建。通过注意力机制，规划器为每个潜在运动基元聚合相关环境上下文：F_traj = PlannerDecoder(Q=A, K=[Z_hist, E_ego], V=[Z_hist, E_ego])。

评分与选择：遵循VAD的评分范式，采用模仿奖励模型和仿真奖励模型估计所有轨迹锚点的模仿奖励r_imt和仿真奖励r_sim，回归网络预测细粒度偏移Δ。总分数s = r_imt + r_sim。输出top-K轨迹：选择总分最高的K个锚点并通过预测偏移精细化为τ_k = a_k + Δ_k。

未来感知奖励器（FAR, Future-aware Rewarder）：虽然TA-DWM可为每个轨迹候选合成未来潜在表示，但为所有候选执行完整去噪过程在实时规划中计算代价过高。FAR通过知识蒸馏绕过推理时的扩散采样：

可学习未来场景查询（Future Scene Queries）Q_fut作为信息瓶颈，提取规划相关的未来特征。未来场景解码器通过与共享上下文Z_hist和候选轨迹嵌入E_traj的交叉注意力交互：F_fut = FutureDecoder(Q=Q_fut, K=[Z_hist, E_traj], V=[Z_hist, E_traj])。

训练时对齐F_fut与TA-DWM生成的目标未来潜在X_0_target：L_distill = ||F_fut - X_0_target||²。未来感知解码器随后用轨迹嵌入查询蒸馏特征：F_state = FutureAwareDecoder(Q=E_traj, K=F_fut, V=F_fut)。MLP将F_state映射为标量奖励r，选择最高奖励的轨迹。

偏好排序训练：将轨迹选择建模为Bradley-Terry偏好排序问题。构建偏好对：使用神谕驾驶分数对比最优候选τ_best与top-K中的次优候选。优化目标最大化正样本获得更高奖励分的似然：L_BT = -log σ(r_best - r_sub)，其中σ为sigmoid函数。

解耦两阶段训练：(1) 仅优化TA-DWM学习以历史上下文和专家运动为条件的潜在动态；(2) 冻结WM后优化多模态轨迹规划器（目标为交叉熵模仿损失+二元交叉熵仿真损失+L1偏移回归）和FAR（目标为L_distill + λ_BT L_BT）。

理解评价

如果把这篇论文放回问题背景里看，它真正的价值在于：端到端自动驾驶旨在根据原始传感器输入生成安全且合理的规划策略，而构建有效的场景表示是一项关键挑战。这说明作者不是只补一个局部模块，而是在重新组织问题该怎样被解决。

最能支撑这个判断的，还是实验给出的证据：此外，为了利用世界模型的远见，我们提出了一个未来感知奖励器，它从冻结的世界模型中提取未来的潜在表示，以实时评估和选择最佳轨迹。换句话说，这些设计并不只是概念上更完整，而是实实在在改变了最终结果。

当然，它离真正成熟的方案还有距离：当前方案的局限在于它仍然受制于计算资源、输入质量或场景复杂度，距离真正稳健的大规模部署还有差距。后续更值得继续推进的方向，是 未来继续提升效率、泛化能力以及在更复杂场景下的稳定性。
