DenoiseSplat：用于噪声 3D 场景重建的前馈高斯泼溅

原文标题：DenoiseSplat Feed-Forward Gaussian Splatting for Noisy 3D Scene Reconstruction

一句话总结： 3D场景重建和新视角合成对VR、机器人和内容创作至关重要。然而大多数NeRF和3DGS管线假设干净输入，在真实噪声和伪影下性能退化。本文提出DenoiseSplat，一种面向噪声多视图图像的前馈3DGS方法：在RE10K上构建了大规模场景一致的噪声-干净基准数据集（注入高斯、泊松、散斑和椒盐噪声并控制不同强度）；设计了噪声感知的特征提取模块从噪声图像中鲁棒地提取多视图特征；在噪声场景中的重建质量显著优于标准前馈3DGS和先降噪后重建的两阶段方法。

简单摘要

3D重建和新视角合成是虚拟现实、机器人导航和数字内容创作的核心能力。以MVSplat为代表的前馈框架直接从稀疏多视图图像预测3D高斯基元，无需逐场景优化。然而这些方法隐式假设输入图像干净无噪，而真实世界的多视图数据——例如网络视频或移动设备拍摄的片段——常存在传感器噪声、压缩伪影和低光退化。噪声不仅破坏几何估计，还损害纹理和细节，尤其在跨稀疏视图融合信息时更为严重。直接的两阶段方案——先用学习式去噪器在2D图像域逐帧去噪，再将去噪图像送入3DGS管线——存在过度平滑、削弱多视图一致性以及增加推理延迟等缺陷。本文提出DenoiseSplat，一种端到端的前馈3DGS方法，让网络自身学会从含噪多视图观测中恢复干净3D场景。

核心创新

1. 提出首个面向含噪多视图输入的端到端前馈3DGS去噪重建框架DenoiseSplat，仅需干净渲染作为监督。

2. 构建基于RealEstate10K的多噪声场景一致性数据集，注入高斯、泊松、散斑和椒盐四种噪声类型。

3. 设计几何-外观解耦的双分支高斯头：几何分支从更稳定、抗噪的线索中预测几何属性，外观分支独立预测颜色以吸收残余噪声。

4. 测试时无需任何优化，单次前向传播即可从含噪多视图输入生成去噪3DGS场景和高质量新视角渲染。

技术细节

DenoiseSplat的目标是从含噪多视图输入直接预测清洁的3D高斯场景表示及渲染结果，在测试时无需外部2D去噪器或测试时优化。其设计围绕三个核心：多噪声类型的数据构建、前馈式高斯泼溅网络、以及跨分支校正机制。

多噪声类型数据构建：基于RealEstate10K（RE10K）数据集，该数据集包含约80,000条视频片段、约一千万帧、覆盖约10,000个YouTube房产视频的相机轨迹。在2D RGB图像域对每帧清洁图像施加四种类型的噪声退化算子：高斯噪声I_noisy = I_clean + N(0, σ²)，σ ∈ [0.02, 0.10]；泊松噪声模拟光子计数过程；散斑噪声（speckle）模拟相干成像系统；椒盐噪声随机翻转像素到极值，总比例采样自[0.01, 0.10]。

场景级噪声配置策略：实际场景中同一场景的多视图通常由相同设备和曝光设置捕获，故噪声类型和强度跨视图应保持一致。因此采用场景级噪声采样：对每个场景s，随机采样噪声类型k_s和强度参数，该场景的所有视图共享相同的噪声配置。所有配置记录在独立元数据文件中。

前馈式高斯泼溅网络（基于MVSplat架构）：由共享多视图2D编码器提取逐视图特征，通过几何对齐的方式将特征提升并聚合形成统一3D表示。具体分为三个阶段：(1) 2D编码器通过ViT从输入图像提取逐视图特征；(2) 几何分支通过代价体和深度/视差估计将2D特征提升至3D；(3) 外观分支在3D空间回归高斯属性（中心μ、协方差Σ、不透明度α、球谐外观参数）。

双分支解耦设计：几何分支和外观分支解耦以提升含噪输入下的鲁棒性。几何分支使用代价体构建和深度/视差候选分布估计场景结构；外观分支基于几何对应关系采样特征，预测球谐系数和颜色参数。

跨分支校正（CBC, Cross-Branch Correction）：外观估计在几何边界区域（深度/视差不连续处和遮挡边缘）容易退化，微小的几何误差可能导致感知上显著的渲染伪影。CBC利用几何导出的边界强度和置信度作为条件信号，对外观分支进行门控残差优化。

边界门控图构建：从几何分支预测的全分辨率视差（或深度）和候选分布上的置信度代理计算：G_boundary = ||∇D_pred||，表示边界强度；C = max p(D|hypotheses)作为置信度代理。门控信号强调同时具有强边界和低置信度的区域：M_gate = G_boundary × (1 - C)。当边界强度强且置信度低时门控值大。

门控残差修正：CBC通过轻量CNN预测残差修正ΔF_app = CNN(F_app ⊕ M_gate) ⊙ M_gate，其中⊕为通道拼接，⊙为逐元素乘积。该设计仅在门控值大的区域应用精细化，抑制边界伪影的同时避免对非边界或高置信度区域的不必要修改。

梯度隔离（Gradient Isolation）：训练时对几何导出信号施加stop-gradient，即从计算图中切断梯度回传。因此CBC仅更新外观分支和CBC模块自身参数，外观梯度不会反传至几何分支。这实现了一种显式的跨分支交互机制：几何提供条件化的边界/置信度线索，外观据此执行门控残差细化。

训练目标：仅在2D图像域进行监督，使用像素级L1损失和SSIM的组合：L = Σ_views [λ_1 ||I_pred - I_clean||_1 + λ_SSIM · SSIM(I_pred, I_clean)]，对所有训练场景和视图求和。

实验结论

在本节中，我们在由 RE10K 构建的噪声多视图数据集上评估所提出的方法。我们首先描述实验设置和基线，然后提出总体结果和定性分析，最后进行消融研究以检查关键设计选择的效果。与 MVSplat-Noisy 相比，在 Denoise-Then-MVSplat 中引入强大的 2D 降噪器可改善所有三个指标。

4.1 实验设置

(iv) 我们的 (DenoiseSplat)，一种 MVSplat 式前馈 3DGS 模型，在我们的噪声干净基准上重新训练，具有噪声输入和干净的 2D 监督，无需测试时优化。

4.2 主要结果

在对噪声输入进行操作的方法中，DenoiseSplat 在 PSNR、SSIM 和 LPIPS 之间实现了最强的整体权衡，并缩小了与干净输入上限 MVSplat-GT 的差距。与 MVSplat-Noisy 相比，在 Denoise-Then-MVSplat 中引入强大的 2D 降噪器可改善所有三个指标。新视图合成通常比可见视图重建对几何不确定性更敏感。

4.3 消融研究

我们沿噪声维度消除鲁棒性，改变噪声类型和强度来检查指标和视觉伪影的趋势。相比之下，DenoiseSplat 显示出更平滑的下降，即使在强噪声下也能保持良好的 LPIPS，这表明噪声强度具有更好的泛化能力。

理解评价

如果把这篇论文放回问题背景里看，它真正的价值在于：在嘈杂的 RE10K 上，DenoiseSplat 在噪声类型和噪声级别的 PSNR/SSIM 和 LPIPS 方面优于普通 MVSplat 和强大的两阶段基线 (IDF + MVSplat)。这说明作者不是只补一个局部模块，而是在重新组织问题该怎样被解决。

最能支撑这个判断的，还是实验给出的证据：为了以受控方式减轻这种跨分支错误传播，我们引入了一种轻量级跨分支校正机制，称为 CBC，它利用几何导出的边界强度和置信度作为条件信号来门控残差 refi。换句话说，这些设计并不只是概念上更完整，而是实实在在改变了最终结果。

当然，它离真正成熟的方案还有距离：尽管取得了这些有希望的结果，但我们的工作仍然存在一些值得进一步探索的局限性。后续更值得继续推进的方向，是 未来继续提升效率、泛化能力以及在更复杂场景下的稳定性。
