ReCoSplat：使用渲染和比较的自回归前馈高斯分布

原文标题：ReCoSplat Autoregressive Feed-Forward Gaussian Splatting Using Render-and-Compar

一句话总结： 在线新视角合成仍具挑战性，需要从连续、通常未知位姿的观测中进行鲁棒场景重建。本文提出ReCoSplat，一种自回归前馈高斯泼溅模型，支持有/无位姿、有/无相机内参的输入。虽然使用相机位姿组装局部高斯比规范空间预测具有更好的可扩展性，但在训练中造成了困境：使用真值位姿确保稳定性但导致分布不匹配，使用预测位姿引入曝光偏差。为解决这一问题，设计了一种混合位姿训练策略——逐步从真值位姿过渡到预测位姿；引入循环一致性损失约束局部高斯在不同位姿假设下的一致性。实验表明ReCoSplat在在线重建质量和鲁棒性上显著优于现有方法。

简单摘要

前馈高斯泼溅直接从输入图像预测3D高斯体，绕过了逐场景优化，但现有方法面向离线重建场景——所有图像一次性可用。在自回归场景中，观测逐步到达，这对具身AI、AR/VR和视频生成至关重要，却几乎未被探索。在线新视角合成的关键设计选择在于训练时使用真实位姿还是预测位姿来组装高斯体：使用预测位姿会耦合高斯预测与位姿估计导致不稳定性，使用真实位姿则假设位姿已知。一种自然的替代方案是训练时使用真实位姿、推理时切换为预测位姿，但这引入了位姿分布不匹配问题。本文提出ReCoSplat，引入渲染-比较模块，受分析-合成范式启发，从组装位姿渲染当前重建并与新图像比较，渲染-观测对比对捕获位姿差异并提供了稳定的几何和视觉先验。此外，针对扩展到数百帧时的KV缓存内存瓶颈，提出混合KV缓存压缩策略。

核心创新

1. 提出渲染-比较模块，将渲染结果与新观测图像进行对比，为高斯预测提供稳定的几何与视觉条件信号。

2. 为每个高斯体增加额外特征维度，丰富渲染信号，使不同输入设置的鲁棒处理成为可能。

3. 设计混合KV缓存压缩策略：截断早期全局注意力层的KV缓存，通过块内全注意力和可训练寄存器token避免信息丢失。

4. 采用可变块大小的课程学习训练策略，支持测试时动态配置，在100帧以上序列中剪枝超90%的KV缓存token。

技术细节

ReCoSplat是一个自回归框架，从连续图像流中以非重叠块（chunk）逐步重建3D场景。其核心创新在于：自回归KV缓存机制、渲染-比较（Render-and-Compare）模块解决位姿分布不匹配、以及针对长序列的KV缓存压缩策略。

自回归处理流程：在时间步t，网络接收新图像块I_t（含可选相机参数K_t, E_t）、此前所有块的KV缓存C_{t-1}、以及累积场景S_{t-1}（包含所有历史3D高斯）。模型估计：G_t^local = f(I_t, C_{t-1}, S_{t-1})，同时预测相机内外参(K̂_t, Ê_t)和更新后的KV缓存C_t。每块局部高斯G_t^local定义在对应图像的相机空间中，通过装配位姿（assembly pose）P_t^asm（可使用真值或预测位姿）变换到世界坐标后合并入累积场景：S_t = S_{t-1} ∪ Transform(G_t^local, P_t^asm)。

自回归主干网络（基于YoNoSplat扩展）：ViT编码器（DINOv2初始化）将每张图像映射为全局相机token c_t和patch token f_t。相机内参由两层的MLP从相机token预测：K̂ = MLP_K(c_t)。Patch token通过36层交替注意力Transformer解码器处理，帧注意力和全局注意力交错，产生多视图特征F_t^dec。

三层预测头：(1) 位势头（Pose Head）从解码器特征预测相机外参：Ê = PoseHead(F^dec)，采用五层逐帧Transformer加两层MLP；(2) 高斯头包括位置头和属性头，各为五层Transformer加线性投影；(3) 特征头为DPT结构，取上采样特征和位置头中间激活为输入，预测高斯特征通道。所有高斯头通过交叉注意力接受渲染-比较模块的条件化token。

KV缓存：维护最后若干全局注意力层的KV缓存。在全局注意力层中，当前块的patch token不仅关注块内token，也关注缓存中的历史token：Attention(Q_t, [K_t; K_{cache}], [V_t; V_{cache}])。使网络在自回归处理中维持对已重建场景的记忆。

渲染-比较模块（Render-and-Compare）：针对训练时使用真值位姿装配而推理时使用预测位姿带来的位姿分布不匹配问题。对当前块的每张图像，以装配位姿P_i^asm渲染累积场景S_{t-1}：R_i = Render(S_{t-1}, P_i^asm)，其中渲染结果包含RGB通道和可学习的特征通道（由特征头解码）。将渲染结果与输入图像拼接后通过三层卷积（含步长下采样）映射到token空间，得到条件token。这些token通过交叉注意力引导高斯预测。设计原理：装配位姿的变化直接影响渲染图像R_i，因此该模块使网络在训练阶段就暴露于位姿变化中，提升推理时位姿不准确下的泛化能力。

KV缓存压缩策略：自回归Transformer的VRAM随序列长度线性增长是主要瓶颈。提出两级压缩：(1) KV缓存截断：发现早期全局注意力层（前10层/共18层）主要提取局部特征而非建立多视图对应关系，因此这些层不存储KV缓存，注意力仅限制在当前块内；(2) 块级保留策略：首个块（尺寸8）保留所有图像的KV token建立初始鲁棒上下文；后续块（尺寸k）仅保留代表性视图——块的最后帧。分配一个独特的可训练寄存器token标记这些保留视图。

空间复杂度分析：标准多视图Transformer对N张图像的每个全局注意力层存储逐图像KV token，空间复杂度O(N·L)。本方法在10个早期层无缓存，剩余8层按压缩策略存储（8个初始token集合 + (N_blocks-1)个后续token集合），总计O(L_init + N_blocks)而非O(N)，常量因子大幅降低。对N=576、k=8的场景（72个块），标准缓存存储4608个token集合，本方法仅312个，内存减少93%。

三阶段训练：(1) 150k步，从YoNoSplat的DL3DV-10K检查点初始化，冻结编码器，采样2-64个上下文视图，块大小固定为8，无缓存压缩；(2) 50k步，引入可变块大小（首块固定8，后续块采样自[4,8]），线性退火最小值从8到4；(3) 50k步，启用完整KV缓存压缩策略。

多任务损失：L = λ_rgb(L_MSE + L_perc) + λ_intr L_intr + λ_extr L_extr + λ_sparse L_1(α)，其中L_perc为LPIPS等感知损失，L_intr惩罚预测焦距与真值的误差，L_extr对所有输入应用成对相对位姿损失，L_sparse对高斯不透明度施加L1正则化并在α<0.005时剪枝。

理解评价

如果把这篇论文放回问题背景里看，它真正的价值在于：我们提出了 ReCoSplat，一种自回归前馈高斯 Splatting 模型，支持有姿势或无姿势输入，有或没有相机内部函数。这说明作者不是只补一个局部模块，而是在重新组织问题该怎样被解决。

最能支撑这个判断的，还是实验给出的证据：为了支持长序列，我们提出了一种混合 KV 缓存压缩策略，将早期层截断与块级选择性保留相结合，对于 100 多个帧，将 KV 缓存大小减少了 90% 以上。换句话说，这些设计并不只是概念上更完整，而是实实在在改变了最终结果。

当然，它离真正成熟的方案还有距离：当前方案的主要局限在于它仍然受到计算资源、输入质量或场景复杂度的约束，离真正大规模稳定部署还有距离。后续更值得继续推进的方向，是 由于变化直接影响渲染图像，因此该模块改进了推理时预测姿势的泛化（表）。
