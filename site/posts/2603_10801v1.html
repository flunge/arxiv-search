PolGS：PolGS++ 用于快速反射 Su 的物理引导偏振高斯溅射

原文标题：PolGS++ Physically-Guided Polarimetric Gaussian Splatting for Fast Reflective Su

一句话总结： 反射表面的精确重建仍是计算机视觉的根本性挑战，在实时虚拟现实和数字内容创作中具有广泛应用。虽然3DGS能以显式表示实现高效新视角渲染，但在反射表面上的表现仍落后于隐式神经方法，尤其在恢复精细几何和表面法线方面。本文提出PolGS++，一种物理引导的偏振高斯泼溅框架用于快速反射表面重建：将偏振BRDF模型集成到3DGS中以显式解耦漫反射和镜面反射分量；引入深度引导的可见性掩码获取机制在无需昂贵光线追踪的情况下实现基于偏振角的切空间一致性约束。仅需约10分钟训练，在合成和真实数据集上的实验验证了该方法的有效性。

简单摘要

反射表面重建是计算机视觉的基本挑战，在实时虚拟现实和数字内容创作中有广泛应用。3DGS虽然以显式表征实现了高效新视角渲染，但在反射表面上的性能仍落后于隐式神经方法，尤其在恢复精细几何和表面法线方面。偏振相机可单次拍摄捕获多角度偏振图像，通过Stokes矢量计算偏振角（AoP），进而推导表面方位角与法线的关系。现有方法在神经隐式表征中利用多视图AoP构建切线空间一致性约束来优化法线估计，但直接将其应用于高斯泼溅框架面临显式可见性定义的缺失。本文提出PolGS，一种物理引导的偏振高斯泼溅框架。核心思路是将偏振BRDF（pBRDF）模型集成到3DGS中，显式解耦漫反射与镜面反射分量，提供物理基础的反射建模和更强的几何线索。同时提出深度引导的可见性掩码获取机制，使基于AoP的切线空间一致性约束可在高斯泼溅中实现。

核心创新

1. 将偏振BRDF（pBRDF）模型首次集成到3DGS框架中，显式解耦漫反射与镜面反射分量。

2. 提出深度引导的可见性掩码获取机制，在不使用光线追踪求交的情况下实现基于AoP的切线空间一致性约束。

3. 通过pBRDF模型同时提供更强的几何线索（法线方向等），改进反射表面精细几何的恢复。

4. 整体设计高效，仅需约10分钟训练即可完成高质量反射表面重建。

技术细节

该框架将多视图偏振图像、对应掩码及相机位姿信息集成，输出包含漫反射和镜面反射分量（以Stokes向量表示的多视图分量）、重建的几何网格、以及估计的环境光照。其核心创新在于将偏振物理信息融入3DGS重建框架，并通过深度引导的可视性掩码实现多视图切线空间一致性约束。

法向表示的分析基础：首先对比了SDF隐式方法与3DGS方法中表面法向的表征差异。在隐式网络如NeuS中，表面法向通过SDF的梯度获得：n = ∇SDF(p)/||∇SDF(p)||，不透明度通过S形函数Φ(SDF(p))给出，优化过程中表面法向与不透明度相互制约——远离表面的点往往具有较低的不透明度值，最终法向由位于表面上的点主导决定。而在3DGS中，对于单个高斯核，不透明度与法向之间缺乏内在关联。像素级约束创建的是一种概率表示，多个高斯核配置可能表示等价的表面几何，引入固有的重建歧义性。这是将偏振信息引入3DGS的理论动机：偏振角（AoP）可以直接约束表面法向。

偏振BRDF（pBRDF）渲染模型：将pBRDF模型融入渲染公式以引入偏振约束。最终渲染模型为：L_total = L_diffuse + L_specular，其中L_diffuse为高斯Surfels渲染后的漫反射颜色，L_specular为CubeMap Encoder评估的镜面反射颜色。镜面反射通过CubeMap方式高效处理，能够处理反射/粗糙表面且由于CUDA实现而维持高计算效率。

双模块网络结构：(1) 高斯Surfels模块：估计物体的漫反射分量，类似于原始高斯Surfels框架，将3D高斯压缩为平面表示以正确定义表面法向；(2) CubeMap编码器模块：类似先前工作评估镜面反射分量，虽不提供粗糙度分量，但有效处理反射/粗糙表面。

深度引导的可视性掩码获取：多视图切线空间一致性约束需要可靠的可视性掩码来确定某表面点是否从邻近视角可观测。在隐式SDF表示中，可通过与SDF的射线追踪经迭代步进评估可视性，但在高斯泼溅框架中缺乏显式的射线-表面相交测试。为解决这一问题，提出深度引导策略：

(1) 构建伪表面点集：通过反投影参考视图的渲染深度图，得到p_surf = o_ref + d·D_ref(u,v)，其中o_ref为参考视相机中心，D_ref为渲染深度图，d为对应单位射线方向。

(2) 计算几何距离：d_geo = ||o_nbr - p_surf||。

(3) 查询渲染深度值：将p_surf投影到邻近视图的图像平面，得到对应像素坐标和渲染深度D_nbr(u',v')。

(4) 定义可视性掩码：M_vis = 1 if |d_geo - D_nbr(u',v')| < ε else 0，ε为考虑高斯混合和离散化导致深度不确定性的容差阈值。该策略无需显式射线追踪即可获得与SDF方法可比的可视性结果。

多视图切线空间一致性损失：基于pBRDF模型和深度引导的可视性掩码：L_tangent = Σ_{p∈S_surf} M_vis(p) · ||A(p) n(p) - b||²，其中n(p)为表面法向，A和b由多视图偏振测量构成的线性系统定义。该损失仅在可视性掩码确认表面点从对应视角可见时才施加切线平面一致性约束。

综合损失函数：L_total = λ_rgb L_rgb + λ_stokes L_stokes + λ_tangent L_tangent + λ_normal L_normal + λ_depth L_depth。其中L_stokes结合非偏振图像渲染损失和偏振Stokes向量渲染损失（类比3DGS的L1+SSIM组合）。
